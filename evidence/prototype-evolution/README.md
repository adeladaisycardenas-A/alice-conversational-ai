# Prototype Evolution Evidence

Selected visual evidence from the development of Alice.

## Original Alice Visual
Early visual direction for Pocket Alice, including the neural-orb interface and Home, Chat, Tools, and Listening concepts.

## Groq + Cartesia Runtime
Working Pocket Alice evidence showing a response generated through Groq using `openai/gpt-oss-120b`, with Cartesia used for spoken output.

## Continuity / Model Independence
Runtime approval evidence showing Alice identity, personality, and local continuity metadata supplied separately to the Groq model.

This supports the core architecture goal: **Alice's continuity and identity are designed to remain separate from the replaceable language model.**

These artifacts document prototype development and testing; they are not presented as evidence of a finished production system.
